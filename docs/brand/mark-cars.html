Momentarily — the train-car system

Two cars seen from above. Identical height, identical width, never touching. Gap is analog — it scales with predicted delay. Height is binary — full means running, reduced means suspended. At rest the mark sits at pause proportions, which for this product is a correct reading rather than a borrowed one.

Verdict after drawing it. The height bit passes the 20px monochrome test cleanly — suspended is instantly findable in a scan and in an aligned list (§5). The analog gap reads at the extremes and is deliberately near-invisible at small delays: a 6-minute delay in this city is normal, so a mark that barely moves there is honest rather than broken. Only material delay visibly spreads the cars. Stadium ends win at display size and cost nothing at 20px, so no optical-size split is needed (§3). The rotated version is dead — dimensionally truer, but it collapses into an equals sign by 32px (§6). The caveat did not survive its own fix. And the property that falls out for free: nominal sits at 0.80 : 1, inside pause proportions, but by ten minutes it is past 1.59 : 1. The logo is a pause button; delay turns it into something that is only itself.

Mapping is exponential-saturating: gap = 4 + 7 · (1 − e−r/12) where r is predicted recovery minutes. Sensitive in the 0–15 min band where riders actually care, compressed in the tail where 45 vs 60 is the same shrug. Bounded by construction, so the mark can never break its own frame.

3 · End treatment — buying back distinctiveness

At pause proportions the silhouette is a pause glyph, and no argument changes that. What can change is texture: square ends read as a UI control, fully rounded ends read as objects — and train cars have rounded ends. Same silhouette family, different signal.

6 · Dimensional honesty — the rotated version

One caveat on the metaphor: a train from above is much longer than it is wide, so strictly, cars nose-to-tail should stack along the travel axis. Rotated, the mark becomes a track diagram and is dimensionally true — but it stops being a pause glyph. Shown for comparison, not as a recommendation.

9 · N cars — and the one rule that keeps it coherent

The primitive scales. But the gap already means delay, so whatever N indexes must be sequential in a dimension where “distance between consecutive items” is meaningful — time or space. Index identity and the gap goes silent, which spends the system's only quantitative channel on nothing.

Size floor: at N=8 a nominal consist is 68 units wide against a car height of 18. These are card-and-row components, never icons. The mark stays 2 forever — N-car strips are a derived pattern, not a logo variant, the same way murk's CSS diamond bullet is a derived use of a fixed mark.

11 · Why nominal could never be zero

Your instinct to reject the joined state was right for a reason past aesthetics. Headway fails in two directions — gapping and bunching — so nominal is a neutral, not a floor. Below 4 the cars crowd; above it they spread. Zero has to stay reserved for “stacked,” which means normal cannot sit there.
