Momentarily — mark study

One geometry: two bars of equal height and fixed width, and a single variable — the gap. Height never varies between the two bars (that is the equalizer trope); the bars never ascend (that is the stock bar-chart trope).

Verdict after drawing it: gap-width alone fails the 20px monochrome test — disrupted and suspended are indistinguishable, so colour ends up doing all the work (§6, row E1). Distance judgments need an anchor and 20 pixels gives none. The system that passes is E3: one bit of topology (joined vs split) plus one bit of height (full vs reduced), both applied symmetrically. Logo and status icon then take different optical sizes of the same primitive — wide gap at display size for uniqueness, tight gap plus height drop at 20px for discriminability.

1 · The gap family

Two rects, w=5 h=18 on a 24 grid, joined at rest. --sep slides them apart symmetrically. Gap steps 0 / 4 / 8 — linear, so severity reads by amount, not by decoding three unrelated shapes.

Shape-encoded, so it survives colorblindness and monochrome. That matches the principle already stated in viz/app/globals.css:441 — “a second encoding so hue isn’t the only signal.” Colors shown are One Dark’s semantic three; the hue decision is still open.

2 · Size ladder

Favicon does all the work here — “momentarily” is 11 characters and cannot carry small sizes the way “murk” can.

3 · Which member is the resting mark?

This was the open question. The geometry answers it: the pause glyph has a tight gap — roughly one bar-width. Push the gap past that ratio and the silhouette stops reading as pause, with no extra element needed.

The two fallback differentiators I floated are rendered for comparison. Both add an element to solve a problem that separation already solves; neither survives 16px as cleanly.

6 · The diagnostic — 20px, colour removed

Strip hue and the shape channel has to stand alone. If you cannot read three states here, the shape encoding is decorative and colour is doing all the work — which fails exactly the users the second encoding exists for. Scan each row as if it were a route grid.
